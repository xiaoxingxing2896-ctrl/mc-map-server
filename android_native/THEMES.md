# 主题工作室（2.3 / 第二阶段）

入口：**我的 → 外观设置 → 打开主题工作室**。工作室跟随当前主题，提供方块景观、主题卡片与「预览 / 设计 / 素材」分区；恢复默认按钮使用独立的安全样式。

- 保留草地方块、幽匿古城、下界堡垒三套内置主题。
- 编辑当前主题或内置主题的副本；修改名称、作者、描述、基础风格、强调色、浅/深背景、圆角、边框、字体、字号和纹理强度。
- 导入 `.mcatlas-theme` 后只进入草稿预览；「只保存副本」加入主题库，「保存副本并应用」保存并切换。每次保存生成新的本地 ID，不覆盖原主题。
- 预览包含地图、登录、Wiki、标记、管理员上传五种组件场景，支持浅/深切换。预览使用示例数据，不登录、不请求上传、不写地图数据。
- 导出当前草稿；系统文件选择器负责导入来源和导出位置。支持删除非当前主题，删除有确认；原始导入文件不受影响。
- 可恢复草地方块，或在本次应用进程内撤回上次主题切换。主题库和当前选择持久化；草稿与撤回记录保留到进程结束，不跨进程恢复。
- 当前主题损坏/丢失时启动回退草地主题。损坏副本仍显示在主题库，可删除。

## 素材与显示规则

支持五种图片：标题景观、页面背景、卡片纹理、导航背景、按钮纹理；以及五个导航图标和一个 TTF/OTF 字体。

PNG/WebP 图片单文件最大 4 MB；景观与纹理最大 1024×1024，图标最大 256×256；所有图片解码像素总量最大 4,194,304（ARGB_8888 约 16 MB）。图片作为静态位图显示。字体最大 8 MB。

导航图标使用透明轮廓并按控件文字色着色，需要同时提供五个，避免已保存主题中导航风格不完整；编辑草稿过程中可以逐个选择。图片重置后回退默认组件。纹理拉伸覆盖所在区域，最多 15% 不透明度，并根据黑/白极端像素下的文字对比度进一步降低。标题景观无正文覆盖，保留完整色彩。

强调色驱动按钮、选择指示和相关面板色；背景编辑限制在所选明暗模式的可读亮度范围内。组件继续使用 Material 交互语义和最小触控尺寸。自定义主题圆角优先于外观设置中的内置主题圆角开关。主题字体倍率与个人、系统字号组合，嵌套预览不会重复乘算。

地图瓦片不重新着色；Wiki 正文继续加载 https://zh.minecraft.wiki/，主题只控制原生界面。主题不能改变账号权限、管理员覆盖确认、网络地址、动效或触感偏好。

## v1 文件协议

`.mcatlas-theme` 是标准单卷 ZIP，必须包含根目录 `manifest.json`。仅接受声明的素材，不接受目录条目、脚本、额外文件、重复文件、路径跳转或未来版本。

```json
{
  "formatVersion": 1,
  "name": "苔石工作台",
  "description": "柔和的苔绿与方块纹理",
  "author": "MC Atlas",
  "baseTheme": "grass",
  "accent": "436B35",
  "darkByDefault": false,
  "style": {
    "radius": 4,
    "border": 2,
    "font": "sans",
    "fontScale": 1,
    "lightBackground": "E9F0DF",
    "darkBackground": "172014",
    "textureOpacity": 0.08
  },
  "assets": { "header": "assets/header.bin" }
}
```

`baseTheme` 为 `grass` / `sculk` / `nether`。`name` 必填，最多 40 字符；作者最多 60，描述最多 180。颜色是无 `#` 的六位 RGB；背景允许空字符串表示默认。圆角 0–24 dp，边框 0–3 dp，字号 0.85–1.15，纹理强度 0–0.15；字体 `sans` / `serif` / `mono` / `custom`，custom 必须附带字体素材。

素材角色：`header`、`background`、`panel`、`navigation`、`button`、`nav_servers`、`nav_wiki`、`nav_map`、`nav_markers`、`nav_profile`、`font`。每项的路径必须为 `assets/<角色>.bin`，内容是原始 PNG/WebP 或 TTF/OTF 字节；扩展名统一为 `.bin`，不依赖来源文件名。不存在素材时省略整个项，使用内置回退。

压缩包最大 20 MB，解压总量最大 20 MB，最多 12 个文件，manifest 最大 64 KB，JSON 深度最多 8。导入经过大小、版本、路径、文件完整性、实际位图尺寸和字体加载校验；保存到应用私有目录中的临时文件，刷盘后同目录重命名。主题库最多 20 个副本、100 MB。

示例包：[Moss-Workbench.mcatlas-theme](examples/Moss-Workbench.mcatlas-theme)。仅包含本项目生成的简单方块图案，不打包 Wiki 图片或 Minecraft 官方资产。

## 动效与触感（延续第一阶段）

标准动效包含按压下沉、导航选中缩放、页面淡入、同明暗配色过渡和地图程序化移动；减少动态限制为最多 100 ms 的短过渡，关闭则立即切换。系统关闭动画时自定义动效关闭。手动拖动地图取消程序化移动。

触感设置独立保存，选择、长按、上传成功使用系统触感事件，间隔至少 100 ms，尊重系统触感开关。主题包不能携带这些设置。

## 验证与边界

`ThemePackageTest` 覆盖往返、非法路径/未知文件、ZIP 截断/CRC、版本/非法配置、资源限额、深度、缺失图标、ID 隔离和颜色对比度；`ThemeDeviceTest` 在 Android 上验证位图解码、独立副本、错误导入不污染主题库、受限删除。场景预览在连接手机上另行检查；此设备的 Compose 测试宿主未能正常启动，因此不将该 UI 自动化尝试计作通过。

这一阶段提供本地主题工作室，不包含主题商店、跨设备同步或 AI 生成（第三阶段）。当前按语义配色生成组件颜色，不单独编辑每个 Material 颜色角色；预览为代表性组件场景，不是实际账号页面快照。
