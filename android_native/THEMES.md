# 内置主题与反馈（2.2 / 第一阶段）

入口为「我的 → 外观设置」，页面标题为「主题与反馈」。目前提供草地方块、幽匿古城、下界堡垒三套内置主题。每套主题控制背景、表面、边框、标题景观和强调色；导航使用统一的语义目的地和代码绘制的方块图标。按钮、输入框、卡片、弹窗和地图按钮统一通过 Atlas 组件封装，底层保留 Material 的交互语义。

选择主题会使用它的建议明暗模式及强调色。用户仍可自行调整明暗、颜色、圆角、文字大小和景观开关；切换主题不会重置字号、圆角、景观、动效及触感偏好。旧版 appearance DataStore 的已有键继续有效，新键缺省时回退草地主题及标准动效。

## 动效

- 标准：按钮按下轻微下沉/缩放，导航选中缩放，页面进入淡入，同明暗模式下背景与表面颜色过渡，地图缩放按钮与坐标跳转平滑移动。
- 减少动态：不做按压缩放或地图平移，只保留最多 100ms 的页面/配色过渡。
- 关闭：应用自定义动效立即完成。Material 自身的基础交互指示继续服从系统设置。
- 系统关闭 Animator duration scale 时，应用自定义动效关闭；在运行期间监听设置变化。
- 地图手势开始时取消程序化移动，保持直接跟手；不会在拖动期间连续振动。动画复用瓦片 ImageRequest，避免每帧重新创建请求。

## 触感

应用内开关独立保存。导航、维度、筛选、开关、标记选择和长按可触发对应事件；普通按钮点击默认不振动。管理员上传只在收到新的服务器成功结果后提供完成反馈，打开旧成功页面不会重复触发。

使用 View.performHapticFeedback，尊重系统触感设置；完成事件在 API 30 以下回退为系统支持的基础反馈，不申请强制振动权限。连续反馈间隔至少 100ms。「体验完成反馈」用于本机检查；真实振感依设备马达和系统设置而异。

## 实现与验证

- ThemeCatalog.kt：内置主题元数据、选择策略与动效策略。
- ThemeColors.kt：主题颜色解析；主按钮颜色按亮度调整，覆盖极端自定义颜色。
- AtlasComponents.kt：组件包装、语义导航图标、按压动效和触感事件。
- Appearance.kt：主题应用、系统设置监听、持久化及设置页面。
- ThemeTest.kt：主题切换保留可访问性偏好、未知主题回退、系统动效优先级，以及三套主题明暗模式和极端强调色下的文字对比度回归。

主题切换不重建整个 Activity 或使用主题 ID 重置页面状态。Wiki 正文由原站负责，应用只控制原生工具栏。

## 后续阶段

本阶段尚不提供外部主题 ZIP 导入、资源编辑/导出、多页面主题工作室、任意字体或 AI 生成。后续应先固定包含格式版本的主题包协议和资源预算，加入原子导入、路径/尺寸校验、预览、删除及损坏回退，再接入后端 AI 草案与素材生成。主题配置不得改变账号权限或管理员上传确认流程。
