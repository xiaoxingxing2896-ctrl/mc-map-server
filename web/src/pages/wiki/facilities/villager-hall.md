交易所是服务器里最重要的公共建筑之一：附魔书、工具、护甲、书架都在这里用绿宝石换。第一次来容易迷路，因为整座建筑分地上和地下两层。

<div class="wiki-callout"><strong>三条硬规矩：</strong>不要击杀村民，不要破坏附魔房的书架，不要往箱子里乱塞东西。村民被杀掉之后要重新繁殖、重新刷交易，成本很高。</div>

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 区域 | 主城 · 地下部分 |
| 入口坐标 | 23 / 65 / 589（地上白色建筑的大门） |
| 结构 | 地上是入口大厅，顺着洞口跳下去是交易区 |
| 开放状态 | 已开放 |
| 产出 / 用途 | 附魔书、工具、武器、护甲、书架，以及附魔房 |
| 负责人 | 待补充 |

## 怎么进去

1. 按坐标走到主城那座**巨大的白色建筑**，大门坐标是 **23 / 65 / 589**。
2. 进门之后往前走，会看到一个向下的洞口，**顺着跳下去**就进入地下的交易区。
3. 地下还有另一个入口（在建筑外侧的洞口），从那里下去是交易区的另一侧；上来的时候走同一个洞口就能回到地面。

进到地下之后会看到一排排由村民组成的「交易单元」。每个单元里站着几个村民，**右键**其中一个就能打开交易界面。

## 交易单元里都有谁

以一个典型单元为例，从左到右依次是：

| 位置 | 村民职业 | 卖什么 | 备注 |
| --- | --- | --- | --- |
| 1–3 | 图书管理员 | 附魔书、书架 | 做神装的核心，建议货比三家 |
| 4 | 工具匠 | 斧、镐、锹、锄 | 用绿宝石买 |
| 5 | 武器匠 | 剑、斧 | 用绿宝石买 |
| 6 | 渔夫 | 钓鱼相关 | 顺路看看就行 |

护甲的出售点在场内另有单元，具体位置到场确认，或者直接问一句。

不确定村民是什么职业时，**右键**打开交易界面，界面上方会显示职业名称。不要为了看职业去打村民——**攻击村民会让交易涨价，甚至让村民无法交易**。

<div class="wiki-callout"><strong>图书管理员前面的告示牌写了什么？</strong>写的是他卖哪本附魔书。先看牌再交易，同样的附魔书不同村民价格差很多，多走两步就能省一半绿宝石。</div>

## 怎么弄到绿宝石

村民不只卖东西，也**收购**物资。把东西卖给村民就能拿到绿宝石，这是新人最快的起步方式：

| 职业 | 收购什么 | 原料来源 |
| --- | --- | --- |
| 图书管理员 | 纸、墨囊 | 甘蔗合成纸，墨囊打鱿鱼 |
| 武器匠 / 工具匠 | 铁锭 | 挖矿、铁农场 |
| 石匠 | 石头、黏土 | 挖矿 |
| 制箭师 | 木棍、羽毛 | 砍树、打鸡 |
| 农夫 | 农作物、南瓜、西瓜 | 种地 |

交易所的箱子里常备这些货，会有人不定时补货。新人直接**拿货换绿宝石**就行，不需要从零种甘蔗。

## 交易流程

1. **右键**村民（不是左键），打开交易界面。
2. 在左侧列表里选你要的交易。
3. 确认背包里有村民要的东西（绿宝石，或者他要收购的物资）。
4. 点击右侧的结果槽完成交易，材料会扣除，物品会进背包。

## 从绿宝石到神装

村民卖的装备**可能自带低级魔咒**，而附魔台只能给「白板装备」（没有任何魔咒的装备）附魔。所以正常流程是：

1. 用绿宝石买白板装备。
2. 如果买到的装备带魔咒，用**砂轮**把魔咒洗掉。
3. 去附魔房，用附魔台和青金石附魔（青金石在交易所的箱子里翻）。
4. 附得不满意就再洗一次，重来。
5. 剩下的高级魔咒，用图书管理员的**附魔书 + 铁砧**打上去。

<div class="wiki-callout"><strong>附魔房的书架不要动。</strong>书架决定附魔台能出的等级，拆一个就掉一级。想拿书请用非精准采集工具去破坏自己带的书架，别动附魔房的。</div>

完整的神装配置、附魔表、铁砧用法和惩罚机制，见 [装备与附魔](/wiki/reference/gear/)。

## 附魔房怎么用

- 中间被选中的、带黄色边框的方块就是附魔台。
- 右键打开，第一个槽放装备，第二个槽放青金石。
- 右侧三个选项从下到上越来越好，最低等级要求也越高（常见是 7 / 9 / 30 级），消耗的青金石分别是 1 / 2 / 3 个。
- 点你想要的选项，等级和青金石会一起扣掉。

## 常见问题

| 现象 | 原因 | 怎么处理 |
| --- | --- | --- |
| 村民不卖东西 / 没有交易选项 | 村民没认领工作站，或者职业被重置 | 在群里报位置，不要自己去放工作站 |
| 价格突然变高 | 有人打过村民 | 报给管理员，等价格自然回落 |
| 交易界面点不动 | 手上拿着东西或背包满了 | 空手、清格子再右键 |
| 附魔台只能出低级魔咒 | 书架被拆了 | 报给后勤，不要自己补 |

## 注意

- **严禁击杀村民**，包括看起来「卡住了」的。卡住请报告。
- **严禁破坏附魔房和装备**。
- 用完把交易界面的东西放回去，不要把箱子搬空。
- 发现村民不见了、机器坏了，按 [反馈与报错](/wiki/reference/report/) 的格式报告。
