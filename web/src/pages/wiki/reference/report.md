这一页解决两件事：**Wiki 本身的错误**怎么提，**游戏里的问题**怎么报。两者渠道不同，附的信息也不同。

## 先分清是哪种问题

| 类型 | 例子 | 找谁 | 要带什么 |
| --- | --- | --- | --- |
| Wiki 内容错误 | 坐标写错、链接失效、步骤对不上 | 在群里发一条，或直接联系维护者 | 页名 + 原文 + 正确内容 |
| 设施损坏 | 漏斗堵了、村民跑了、拉杆没反应 | 后勤 | 设施名 + 坐标 + 现象 + 截图 |
| 物资纠纷 | 东西被拿走、建筑被拆 | 管理员 | 坐标 + 大致时间 + 截图 |
| 账号问题 | 进不去、白名单、权限不对 | 管理员（私聊） | 游戏 ID + 报错原文 |
| 服务器异常 | 全服卡顿、掉线、TPS 暴跌 | 管理员 | 发生时间 + 当时在做什么 |

## 报设施问题的模板

```
设施：末地小黑塔
坐标：／warp 小黑塔 到达后，主掉落区
时间：今天 21:30 左右
现象：站在挂机位没有血槽，怪也不刷
已尝试：退出重进、换了个位置站
截图：（附图）
```

<div class="wiki-callout"><strong>截图比一百字描述都准。</strong>能截就截。尤其是报方块、拉杆、村民这类问题，一张图能省掉三轮来回确认。</div>

## 报 Wiki 错误的模板

```
页面：/wiki/facilities/iron-farm/
问题：坐标写成了 xx / xx / xx，实际应该是 xx / xx / xx
依据：群公告 2025-xx-xx 那条，或者现场截图
```

## 三条不要

- **不要自己动手修。** 生电机器结构复杂，越修越坏是常态。你看到的现象本身就是重要的诊断信息，先保住现场。
- **不要在公共频道刷屏。** 同一句话连发五遍不会让问题解决得更快，只会被无视。
- **不要相信私聊里的「我帮你刷物品 / 我帮你解封」。** 管理员不会私聊索要账号密码。

## 处理需要多久

没有固定时效，看当时谁在线。紧急情况（全服卡死、机器正在被破坏）可以在群里直接 `管理员`，其余情况按上面的模板发一条，等回复就行。

## 想直接改 Wiki？

可以。Wiki 的源文件在仓库里，每一页都是 Markdown：

- 内容页在 `web/src/pages/wiki/` 下，按目录分组。
- 新增设施页时复制 `web/src/pages/wiki/facilities/_template.md`，下划线开头的文件不会生成页面。
- 改完记得在 [变更日志](/wiki/reference/changelog/) 里加一条。

<div class="wiki-callout"><strong>写之前先核实。</strong>一处坐标写错，可能让新人白跑半小时，也会让后面维护的人不敢相信这一页。</div>
