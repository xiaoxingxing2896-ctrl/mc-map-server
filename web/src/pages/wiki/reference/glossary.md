群聊里一天能出现几十个黑话。这一页把 Wiki 里用到的说法集中解释，按词条字面顺序排，方便 Ctrl+F。

## 玩法与装备

| 说法 | 意思 | 在哪会遇到 |
| --- | --- | --- |
| 生电 | 「生存 + 红石电路」。靠设计机器自动生产资源，而不是纯手工挖 | 全站 |
| 满配 | 一件装备打满了该有的魔咒 | [装备与附魔](/wiki/reference/gear/) |
| 神装 | 满配的钻石装备，生存模式能拿到的最好装备 | 同上 |
| 白板装备 | 没有任何魔咒的装备。附魔台只能给白板装备附魔 | [村民交易所](/wiki/facilities/villager-hall/) |
| 附魔书 | 带魔咒的书，用铁砧把魔咒打到装备上 | [装备与附魔](/wiki/reference/gear/) |
| 宝藏型魔咒 | 附魔台刷不出来的魔咒，只能靠附魔书、村民、钓鱼或战利品箱 | 同上 |
| 经验修补 | 捡经验自动修耐久的魔咒，做神装的必需品 | 同上 |
| 铁砧惩罚 | 同一件装备反复上铁砧会累积惩罚，最终「过于昂贵」 | 同上 |
| 砂轮 | 洗掉装备魔咒的方块。买到的装备要先洗白才能附魔 | 同上 |
| 工位 | 村民认领的工作站点方块。工位没了，村民会失业 | [铁农场](/wiki/facilities/iron-farm/) |

## 设施与地点

| 说法 | 意思 | 在哪会遇到 |
| --- | --- | --- |
| 交易所 | 村民交易大厅，附带附魔房。在主城地下 | [村民交易所](/wiki/facilities/villager-hall/) |
| 附魔房 | 交易所里放附魔台和青金石的房间 | 同上 |
| 小黑塔 | 末地的末影人刷怪塔，主要用来刷经验 | [刷怪与经验农场](/wiki/facilities/mob-farm/) |
| 猪人塔 | 下界的僵尸猪灵塔，刷经验同时刷金锭 | 同上 |
| 经验农场 | 泛指所有刷经验的机器，本服主要指上面两座 | 同上 |
| 刷怪上限 | 一定范围内能同时存在的怪物数量上限，被占满就不刷怪 | 同上 |
| 出生区 | 出生点周围的一片区域，属于公共区域 | [坐标准则](/wiki/map/overview/) |
| 主城 | 交易所、附魔房所在的城区 | 同上 |
| 地狱交通 | 在下界铺设的快速交通网络，靠传送门连接主世界各点 | 同上 |
| 线路 / 站点 | 地狱交通的编号路线（3 号线、7 号线…）和停靠点 | 同上 |

## 操作与规矩

| 说法 | 意思 | 在哪会遇到 |
| --- | --- | --- |
| warp / 传送点 | `/warp 名称` 形式的传送指令，能直接送到设施门口 | [常用指令](/wiki/start/04-commands/) |
| 挂机 | 站在某个位置让机器持续运转，人不在操作 | [设施总表](/wiki/facilities/) |
| 卡服 | 服务器卡顿、TPS 掉下来，通常由高频红石或大量实体引起 | [服务器规则](/wiki/start/03-rules/) |
| 区块 | 16×16 格的世界单位。机器必须在加载中的区块里才会运转 | 全站 |
| 后勤 | 负责公共物资、公共设施维护的玩家 | [去哪问人](/wiki/start/05-where-to-ask/) |
| 腐竹 | 「服主」的谐音，服务器的主人 | 同上 |
| 复位 | 用完设施后把拉杆、按钮、门恢复原状 | [设施总表](/wiki/facilities/) |
