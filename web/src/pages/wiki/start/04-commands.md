服务器装了什么插件决定了哪些指令可用。下面把「已经确认能用」和「常见但需要自己试一下」分开写，免得照着敲一遍全是红字。

<div class="wiki-callout"><strong>指令前缀以服务器实际配置为准。</strong>如果输入后提示未知指令，说明这台服没装对应的插件，不用怀疑自己打错了。</div>

## 已确认可用

| 指令 | 作用 | 备注 |
| --- | --- | --- |
| `/warp 小黑塔` | 传送到末地小黑塔（经验农场） | 免去走末地传送门，使用规则见 [刷怪与经验农场](/wiki/facilities/mob-farm/) |
| `/warp 猪人塔` | 传送到下界僵尸猪灵塔（经验农场） | 到达后先确认机器是否开启 |

传送点列表会随建设增加。想看完整列表，在游戏里输入 `/warp` 不带参数，一般会列出全部可用点；列表不在 Wiki 里维护，因为会频繁变动。

## 常见但需要先确认

这些指令在多数服务器上都有，但依赖插件和权限组。第一次用之前，建议先在群里问一句，或者自己试着敲一下看有没有反应。

| 指令 | 大致作用 | 说明 |
| --- | --- | --- |
| `/spawn` | 回出生点 | 有该指令时可作紧急回城 |
| `/tpa <玩家>` | 请求传送到某人身边 | 需要对方同意；不要连续催 |
| `/home` / `/sethome` | 设置、回到个人家 | 可设置数量以服务器配置为准 |
| `/back` | 回到上一次死亡或传送的位置 | 部分服务器禁用（会削弱生存感） |
| `/msg <玩家> <内容>` | 私聊 | 也可用 `/tell` |
| `/list` | 查看在线玩家 | 想找人帮忙时先看谁在线 |
| `/help` | 查看可用指令 | 最稳的一招：不确定就 `/help` |

## 不要用的指令

| 指令 | 为什么不能用 |
| --- | --- |
| `/gamemode`、`/give`、`/tp` 等管理指令 | 只有管理员能用。尝试使用不会生效，但记录里会很难看 |
| 任何来源不明的「刷物品」指令 | 大概率是骗局或者漏洞，用了就是违规 |
| 循环执行的定时指令 | 容易造成卡顿，需要报备 |

## 记不住怎么办

把常用的两三个写在告示牌上挂在自己家门口，比每次翻 Wiki 快。真正需要经常用的其实只有：回出生点、去经验农场、找人。
