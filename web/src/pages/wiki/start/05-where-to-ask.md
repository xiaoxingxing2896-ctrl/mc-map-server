服务器没有全天候客服。问得清楚，几乎都会有人答；问得含糊，容易被忽略——不是冷漠，是不知道从哪答起。

## 先自查，再提问

1. **翻这个 Wiki。** 进服、规则、指令、设施使用，四类问题基本都在站内。
2. **搜群聊记录。** 你遇到的问题，大概率有人问过。搜关键词：地点名、指令名、报错原文。
3. **再在群里问。** 一句话说清楚「在哪、想做什么、卡在哪一步」。

<div class="wiki-callout"><strong>不要私聊骚扰。</strong>同一个问题不要同时私聊三个人，也不要在公共频道连续 @ 管理员。没人回的时候，隔一段时间再问一次就够。</div>

## 什么问题找谁
![](/wiki/img/wiki-20261021-062553-jfpeo5.png)
| 问题类型 | 找谁 | 说明 |
| --- | --- | --- |
| 房被拆了、东西丢了 | 管理员 + 后勤 | 附上坐标和大致时间，越具体越好 |
| 公共设施坏了（漏斗堵、村民跑了） | 后勤 | 说清楚是哪座设施、哪一部分，别自己动手修 |
| 想做大型红石机器 | 管理员 | 先说范围和作用，避免卡服和撞车 |
| 账号、白名单、权限 | 管理员 | 涉及身份，私聊处理 |
| 坐标、怎么走、某座农场怎么用 | 先看 Wiki，再看群里老人 | 这类问题 Wiki 里都有 |
| 服务器崩了、全体掉线 | 等公告，别刷屏 | 管理员通常已经知道了 |

## 提问模板

直接复制这段，把括号里的内容换掉：

```
【问题】一句话说明现象，例如「交易所的附魔台打不开」
【位置】坐标 x / y / z，或者设施名，例如「交易所地下，附魔房」
【时间】大概什么时候发现的，例如「刚才 21:30 左右」
【截图】能截图就截图，比描述准十倍
【已尝试】我已经试过退出重进、换角度右键
```

## 哪些事不要做

- **不要在公共频道刷屏求助。** 刷屏只会让人屏蔽你。
- **不要自己动手修别人的机器。** 你不是原作者，拆开容易越修越坏。
- **不要相信「我帮你刷物品」的私聊。** 这类话术几乎都是骗局。
- **不要把管理员的私下回复截图外传。** 处理结果以公告为准。
