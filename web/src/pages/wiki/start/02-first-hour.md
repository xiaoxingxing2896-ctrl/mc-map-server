进入服务器的第一个小时，最容易犯的错不是不会玩，而是**太急着玩**：在出生点盖房子、把公共箱子搬空、一个人往几万格外跑。

这一页给一个保守但不出错的顺序。

## 时间线

| 时间 | 做什么 | 为什么 |
| --- | --- | --- |
| 0–10 分钟 | 只在出生点周边看，F3 记坐标 | 先认路，比先造东西重要 |
| 10–25 分钟 | 看群公告里的新人说明，找公共仓库 | 服务器通常会给新人留起步物资 |
| 25–40 分钟 | 沿主路走一段，认一下交易所或主城方向 | 后面所有交易、附魔都在那一带 |
| 40–55 分钟 | 找一处临时落脚点，把床放下 | 死亡后能复活在附近，不用重走 |
| 60 分钟 | 定一个小目标：砍树、挖石、或者去看一座农场 | 有目标才不会乱逛 |

<div class="wiki-callout"><strong>先别建。</strong>第一小时不要在地面上起房子、不要挖大坑、不要砍出生点周围那几棵树。想建东西，请先走出一段距离，或者问清楚哪里是建筑区。</div>

## 第一小时该做 / 不该做

| 该做 | 不该做 |
| --- | --- |
| 用 F3 记下出生点坐标 | 在出生点铺路、盖房、插火把 |
| 拿够用的起步物资 | 把整箱物资搬回自己家 |
| 沿主路走，看清地形 | 往没人的方向跑到几万格外 |
| 死一次，记住复活点 | 跳进没看清深度的矿洞 |
| 在群里问「哪里能建」 | 自己找块空地就开工 |

## 生存底线

- **不要拿别人的东西。** 没有写「公共」的箱子都是私人的，包括看起来像是忘了锁的。
- **不要动别人的机器。** 生电机器里一个拉杆、一个漏斗朝向都是设计过的。
- **不要在下界和末地乱挖。** 下界破坏地形很难复原，末地平台是公共交通的一部分。
- **不要挂机刷怪。** 除非设施页面明确写了可以挂机，否则挂机会占着刷怪上限，别人就打不到怪了。

## 想快点变强？

先别急着挖矿。服务器有公共的村民交易所，附魔书、工具、护甲都能用绿宝石换；经验可以去经验农场刷。完整流程看 [装备与附魔](/wiki/reference/gear/)，设施位置看 [设施总表](/wiki/facilities/)。
