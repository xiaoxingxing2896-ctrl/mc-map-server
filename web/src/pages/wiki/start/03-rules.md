这份规则是站内的**摘要与解释**，方便新人一眼看懂。正式条款、惩罚力度和申诉方式，一律以群公告为准。

## 四条基本原则

1. **不破坏**：不拆别人的建筑、机器、地基，包括废弃建筑。
2. **不侵占**：别人圈定的区域、正在施工的工地，先问再加东西。
3. **不卡服**：不堆高频红石，不批量生成实体，不长时间挂着大量区块加载。
4. **不刷屏**：公共频道里不发广告、不刷指令、不连续 @ 人。
5. **不矿透**：一经发现，直接封禁，没得商量

## 分类细则

### 建筑与区域

- 出生点周边、主城、公共道路属于公共区域，不得私人占用。
- 想建大工程，先在群里说一声范围，避免和别人撞车。
- 建筑可以不上锁，但**私有容器请在告示牌上写名字**；没写名字也不代表可以随便拿。

### 公共设施

- 公共农场的产物按需取用，不要一次性清空。
- 使用农场后把拉杆、按钮、门恢复到原来的状态。
- 发现设施损坏（漏斗堵了、村民跑了、拉杆失灵），立刻在群里说，不要自己拆开修。

### 红石与机器

- 高频红石、大量掉落物、批量生成生物都会让服务器掉 TPS。做之前问一句。
- 不要在别人机器旁边建同类型的机器，刷怪上限会互相抢。
- 挂机请使用服务器认可的挂机点，具体位置以群公告为准。

### 交流与账号

- 不冒充管理员，不发布虚假公告。
- 账号自己保管，不要借号；借号产生的后果由号主承担。
- 有矛盾先在私下说清楚，不要在公共频道对线。

## 常见红线与处理

| 行为 | 定性 | 通常处理 |
| --- | --- | --- |
| 偷拿他人物资 | 严重 | 归还并道歉，屡犯会被处理 |
| 拆毁他人建筑 / 机器 | 严重 | 协商修复或赔偿，情节严重会封禁 |
| 击杀交易所村民、破坏附魔房 | 严重 | 立即报告，由管理员处理 |
| 高频红石卡服 | 中等 | 先提醒，拒不整改会被强制下线 |
| 在公共频道刷屏、发广告 | 轻微 | 口头提醒，重复会被禁言 |
| 恶意 PVP、恶作剧 | 视情节 | 未经同意的 PVP 一律视为违规 |

<div class="wiki-callout"><strong>惩罚不是目的。</strong>大多数问题在群里说一声就能解决。真正会走到封禁的，通常是「反复破坏」和「被提醒了还不改」。</div>

## 关于借东西和「借用一下」

想用别人的东西，**先问**。对方没回，就当没同意。使用后放回原处，消耗品按量补充。

## 发现有人违规怎么办

不要在公共频道点名对线，也不要去拆对方的建筑「讨说法」。按 [反馈与报错](/wiki/reference/report/) 的格式，把时间、坐标、截图发给管理员。
