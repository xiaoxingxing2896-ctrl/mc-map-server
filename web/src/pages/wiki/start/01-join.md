「一辈子存档」是 Java 版的生电（红石技术）服务器，长期存档、不删档。进服流程本身不复杂，卡人的通常是版本对不上和地址抄错。

## 需要准备的东西

| 项目 | 说明 | 在哪确认 |
| --- | --- | --- |
| Java 版客户端 | 服务器是 Java 版，基岩版进不来 | 官方启动器或第三方启动器 |
| 游戏版本 | 必须和服务端一致，版本不对会被直接拒绝登录 | 以群公告为准 |
| 服务器地址与端口 | 形如 `地址:端口`，注意冒号是英文冒号 | 以群公告为准 |
| 内存分配 | 客户端建议分配 4 GB 以上，进出生点不容易卡 | 启动器设置 |
| 群 | 地址、版本、维护通知都在群里，不进群等于闭着眼玩 | 由管理员邀请 |

<div class="wiki-callout"><strong>地址和版本不要问 Wiki。</strong>这两项会随更新变化，Wiki 里写死反而误导人，统一以群公告和群置顶为准。</div>

## 进服步骤

1. **加群，先看置顶。** 把公告从头翻一遍：服务器地址、版本、是否白名单、当前是否在维护，都在这几条里。
2. **确认版本。** 启动器里把版本切到公告写的那个版本。装了模组或光影的话，先不加任何模组裸连一次，确认能进再逐个加回来。
3. **添加服务器并登录。** 第一次进服会被放到出生点附近。此时**不要**放方块、不要挖方块、不要往远处跑。
4. **读一遍规则。** 群公告里一般有链接，站内的版本在 [03 服务器规则](/wiki/start/03-rules/)。
5. **记住回出生点的路。** 用 F3 看坐标，把出生点的 x / y / z 记在便签里，比记地形靠谱。

## 登录之后先做三件事

- 按 **F3** 打开调试界面，找到 `XYZ` 那一行，确认自己站在哪里（坐标写法见 [坐标准则](/wiki/map/overview/)）。
- 在群里打个招呼，报一下游戏 ID，方便别人认人。
- 如果你打算长期玩，问一下有没有需要走的登记流程；没有的话就可以直接开始。

## 常见登录问题

| 现象 | 常见原因 | 怎么处理 |
| --- | --- | --- |
| 提示版本不兼容 / 直接断开 | 客户端版本与服务端不一致 | 按群公告的版本重开，先不加模组 |
| 一直停在「正在加入世界」 | 网络问题，或服务器正在重启 | 等一两分钟重试，仍不行在群里问 |
| 进去后很卡、方块不加载 | 分配内存不足、渲染距离过高 | 内存调到 4 GB 以上，渲染距离降到 8~10 |
| 提示被踢出 / 无权限进入 | 白名单未加，或正在维护 | 在群里问管理员，不要反复重连刷屏 |
